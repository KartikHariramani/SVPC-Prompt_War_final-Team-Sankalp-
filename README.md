# PromptWars 2026 — Decision Blind Spot Analyzer (Team Sankalp)

## Problem Statement
People often make decisions based on the information most visible to them, but fail to consider critical blind spots, missing information, conflicts of interest, and underlying assumptions.

## Solution
PromptWars Decision Blind Spot Analyzer is an AI-powered Decision Intelligence SaaS that acts as a cognitive partner. Instead of making decisions for the user, it interrogates their reasoning through dynamic, adaptive questions generated by Gemini AI, forcing the user to critically evaluate their own assumptions. 

## Key Features
- **AI Decision Intelligence:** Analyzes decision logic using Google Gemini AI.
- **Dynamic Questions:** Generates localized, context-aware adaptive questions in Roman English/Hinglish based specifically on the user's initial reasoning.
- **Blind Spot Detection:** Identifies critical areas the user has overlooked.
- **Assumption Analysis:** Highlights unstated or risky assumptions.
- **Missing Information:** Points out data required before making a final choice.
- **Conflict Detection:** Identifies competing priorities or conflicts of interest.
- **Impact Analysis:** Assesses qualitative impact on Finance, Career, Lifestyle, etc.
- **What-if Scenarios:** Supports generating hypothetical scenarios based on changed constraints.
- **Activity & Calendar Context:** Interfaces with Telegram activity data and Calendar connections to ground assumptions in reality (e.g. comparing assumed free time vs. actual occupied schedule).

## Tech Stack
- **Frontend:** React + Vite, Tailwind CSS, Recharts
- **Backend:** Node.js, Express
- **Database:** Supabase PostgreSQL
- **AI:** Google Gemini API (gemini-3.8-flash)
- **External Integrations:** Telegram Bot API
- **Realtime:** Supabase Realtime

## Architecture
```
USER
 ↓
REACT / VITE FRONTEND
 ↓
EXPRESS BACKEND
 ↓
 ├── SUPABASE DATABASE
 ├── SUPABASE REALTIME
 ├── GEMINI API
 └── TELEGRAM API
```

## Database (Supabase Schema)
- `decisions`: Stores core decision data and context.
- `decision_questions`: Dynamically generated AI questions.
- `decision_answers`: User responses to AI questions.
- `analyses`: Full JSON response from Gemini mapping out the blind spots.
- `activities`: Real-time activity tracking mapped from Telegram.

## Environment Variables
Create a `.env` file in the root of the project with the following structure (do NOT commit secrets):

```env
# Backend variables
GEMINI_API_KEY=your_gemini_key
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token

# Frontend variables
VITE_API_URL=http://localhost:5000
```
*(See `.env.example` for details).*

## Local Setup
1. Clone the repository: `git clone https://github.com/KartikHariramani/SVPC-Prompt_War_final-Team-Sankalp-.git`
2. Run `npm install`
3. Configure your `.env` keys.
4. Apply `update_schema.sql` to your Supabase SQL Editor.
5. Start both servers: `npm run dev`

## Deployment
- **Frontend (Netlify):** Set `VITE_API_URL` to your Render backend URL, set the build command to `npm run build`, and publish the `dist` directory.
- **Backend (Render):** Deploy as a Web Service running `npm start`. Configure your environment secrets in the Render dashboard.
